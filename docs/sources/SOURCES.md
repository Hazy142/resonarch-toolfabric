# Source and derivation register

ToolFabric is derived from recurring engineering rules in resonArch repositories and an external comparison with obra/superpowers.

The machine-readable registry pins repository, revision, path, and derivation role.
A source link is not automatically evidence for every claim: authority, scope, independence, and the exact rule being derived remain explicit.

Recurring derivations include authority boundaries, append-only evidence, fail-closed behavior, unchanged-byte promotion, repository instructions before generic workflows, untrusted tool/retrieval output, durable task state, and provider-independent contracts.

See source-registry.json for the pinned identities.
